# Quiz

Квиз для игры с друзьями: ведущий создаёт комнату, игроки заходят по коду, ссылке или QR-коду.
Весь сайт — один файл `index.html`, данные хранятся в Firebase Realtime Database.

## Настройка Firebase (один раз)

1. **Authentication → Sign-in method:** включить **Anonymous** (для игроков) и **Google** (для ведущего).
2. **Authentication → Settings → Authorized domains:** добавить домен сайта (например, `ваш-логин.github.io`).
3. **Realtime Database → Правила:** вставить содержимое файла `database.rules.json` и нажать «Опубликовать».
4. **Сделать себя ведущим:** открыть сайт, нажать «Я ведущий» и войти через Google.
   Появится экран «Нет прав ведущего» с вашим ID. В **Realtime Database → Данные** создать узел `hosts`,
   а в нём запись: ключ — ваш ID, значение — `true` (логическое, не строка).
   Ещё одного ведущего можно добавить так же.

## Что защищают правила

- Создавать и вести игры могут только аккаунты из `hosts`.
- Игрок может записать только своё имя (до 20 символов) и свой ответ: один раз, только на текущий вопрос,
  только пока идёт время, и с серверным временем.
- Очки и результаты считает и записывает только ведущий.
- Список всех комнат недоступен игрокам; комнату можно прочитать только зная её код.
- При создании новой комнаты удаляются комнаты старше 24 часов.
